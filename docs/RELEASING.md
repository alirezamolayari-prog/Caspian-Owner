# انتشار نسخه جدید

## خلاصه (۳ قدم)
۱. **شماره نسخه را بالا ببرید** (در پوشه پروژه، در PowerShell):
```powershell
powershell -File tool/bump_version.ps1 -Part patch
```
- `patch` برای اصلاح‌های کوچک، `minor` برای امکانات تازه، `major` برای تغییرهای بزرگ.
- شماره ساخت (عدد بعد از `+`) خودکار یکی بالا می‌رود. اندروید به‌روزرسانی با شماره کمتر یا برابر را نمی‌پذیرد.

۲. **تغییرات را بنویسید.** در `docs/CHANGELOG.md` زیر عنوان نسخه تازه، چند خط ساده و کوتاه برای مالکان بنویسید (همین متن در پنجره «به‌روزرسانی» روی گوشی نشان داده می‌شود).

۳. **منتشر کنید:**
```powershell
git commit -am "Release 1.2.0"
git tag v1.2.0
git push
git push --tags
```
(به‌جای `1.2.0` شماره‌ای را بنویسید که قدم ۱ نشان داد.)

بعد از آن **صبر کنید** تا کار GitHub با نام «Release» تمام شود (حدود ۱۰ دقیقه). نتیجه را در صفحه Actions مخزن ببینید.

**گوشی‌ها خودشان به‌روز می‌شوند:** برنامه هنگام باز شدن (و حداکثر روزی یک بار) نسخه تازه را پیدا می‌کند، تغییرات را نشان می‌دهد و با «به‌روزرسانی» فایل را دانلود، بررسی و نصب می‌کند.

## اجبار به به‌روزرسانی
اگر نسخه‌های قدیمی دیگر نباید کار کنند، پیش از قدم ۳ عدد داخل `tool/min_supported_build.txt` را برابر شماره ساخت نسخه تازه بگذارید. گوشی‌هایی که شماره ساختشان کمتر است تا به‌روز نشوند وارد برنامه نمی‌شوند.

## اگر Release شکست خورد
- «Signing secret … is missing»: یکی از رازهای GitHub (کلید امضا) تعریف نشده است. با `gh secret set <نام>` دوباره تعریفش کنید.
- «Tag … does not match pubspec.yaml»: برچسب با شماره نسخه یکی نیست. برچسب را پاک کنید (`git tag -d v1.2.0` و `git push --delete origin v1.2.0`)، شماره درست را بزنید و دوباره منتشر کنید.
- آزمون‌ها شکست خوردند: اشکال باید اول درست شود؛ نسخه معیوب منتشر نمی‌شود.

## کلید امضا (بسیار مهم)
- فایل `E:\keys\caspian-owner-release.jks` و رمزهایش فقط روی کامپیوتر شما، در KeePassXC و در ۳ پشتیبان هستند.
- **اگر این کلید گم شود، اپ نصب‌شده دیگر هرگز به‌روز نمی‌شود** و همه باید برنامه را پاک و دوباره نصب کنند.
- اثر انگشت گواهی امضا (عمومی است و رمز نیست). هر APK منتشرشده باید همین را نشان دهد:
  `SHA-256: f332c7e7cd436e224f428c2a682d217a1f56c9a4b4bf1c1d7f410147c9c468ec`
  بررسی: `apksigner verify --print-certs caspian-v1.2.0.apk`

## برای توسعه‌دهنده
- منبع نسخه: `version: X.Y.Z+BUILD` در `pubspec.yaml`.
- `tool/make_update_manifest.dart` فایل `update.json` را می‌سازد (نسخه، شماره ساخت، حداقل ساخت، نشانی APK، SHA-256، حجم، تغییرات فارسی).
- برنامه فایل را به ترتیب از این نشانی‌ها می‌خواند: نشانی سرور (وقتی سرور راه بیفتد) و سپس `https://github.com/alirezamolayari-prog/Caspian-Owner/releases/latest/download/update.json`.
- از نسخه ۰٫۲٫۰، APK منتشرشده «همه‌کاره» است (arm64-v8a، armeabi-v7a و x86_64) تا روی هر گوشی، قدیمی یا جدید، نصب شود. نام فایل `caspian-vX.Y.Z.apk` است.
