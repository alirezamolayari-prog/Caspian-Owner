# Caspian Owner (مالک کاسپین)

Private Android app for the owners of Caspian furniture mall: approve escalated goods requests, see warehouse stock, order surprise counts, chat about a request, and ask the «دستیار کاسپین» assistant.

- Flutter (Android only), Material 3, fully RTL Persian.
- Runs on **mock data** until the middle server exists. The API contract is in `api/openapi.yaml`.
- Distributed as an APK with its own in-app updater (no Google Play, no Google Play Services).
